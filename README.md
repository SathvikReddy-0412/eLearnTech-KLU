# eLearnTech@KLU

An interactive Microcontroller & Embedded Systems Learning Portal for the **STM32 NUCLEO-H753ZI** development platform, built for KL University.

## Features
- **Board Specs & Hardware Explorer**: Overview of Cortex-M7 features, memory maps, and specs.
- **Lab Experiments**: Interactive step-by-step laboratory manual with code syntax highlighting, circuit pin connections, and expected hardware outcomes.
- **Pinout Visualizer**: Interactive signal filtering (GPIO, USART, SPI, I2C, CAN, ADC, DAC, Timers) for 144-pin Zio/ST morpho headers.
- **Embedded Hardware Calculators**: Baud rate, timer prescaler, ADC conversion time, and PWM duty cycle calculators.
- **Quiz & Knowledge Assessment Engine**: Interactive quizzes with immediate evaluation and progress tracking.
- **Printable Lab Report Generator**: Auto-generate lab progress reports for university evaluation.

## Tech Stack
- React 19 + Vite
- Tailwind CSS
- Lucide React Icons
